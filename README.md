# 🌿 Greenden Website

Greenden is a modern and responsive plant-themed website developed using **HTML** and **Tailwind CSS**. The website is designed to provide a clean, simple, and attractive user interface for displaying plants and gardening products.

## 📌 About the Project

This project is a frontend website created as part of my **Frontend Development learning journey**. The main goal of this project was to practice building responsive web pages using **HTML** and **Tailwind CSS**.

The website contains three main pages:

* 🏠 **Home** – Introduction to the website with featured content and plant-related sections.
* 🪴 **Product** – Displays different plants and products in an organized layout.
* 📞 **Contact** – Provides a contact section for users to get in touch.

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and content of the webpages.
* **Tailwind CSS** – Used for styling, layouts, colors, spacing, typography, and responsive design.
* **Visual Studio Code** – Used for developing the project.
* **Git & GitHub** – Used for version control and project hosting.

## 📄 Pages

### 🏠 Home Page

The Home page introduces the Greenden website and provides an attractive overview of the plant-related products and services. It includes the navigation bar, main content sections, and featured plant information.

### 🪴 Product Page

The Product page showcases different plants/products using a clean and organized layout. Tailwind CSS was used to create responsive product sections and maintain consistent spacing and styling.

### 📞 Contact Page

The Contact page provides a simple interface for users to contact the website. It contains the necessary contact-related sections and demonstrates form and layout styling using Tailwind CSS.

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

2. Open the project folder in **Visual Studio Code**.

3. Open `index.html` in your browser.

4. You can also use the **Live Server** extension in VS Code to run the website.
